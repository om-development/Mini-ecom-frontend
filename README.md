# Mini Ecom 🛒

Mini Ecom is a full-stack e-commerce website I built using the MERN stack.

The project started as a simple e-commerce MVP and grew into a complete application with authentication, product management, cart, addresses, checkout, and orders.

## What it has

- User signup and login
- JWT authentication using HTTP-only cookies
- User and admin roles
- Product browsing and product details
- Search and category filtering
- Admin product CRUD
- Shopping cart
- Address management
- Checkout and orders
- Responsive design

## Tech I used

### Frontend
- React
- React Router
- Tailwind CSS
- Material UI (MUI)
- Axios
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- cookie-parser
